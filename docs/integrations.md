# Provider integrations

## WhatsApp

Use the pinned public image `devlikeapro/waha:latest-2026.10.1` with `WHATSAPP_DEFAULT_ENGINE=GOWS`. For an ARM64 VPS use `devlikeapro/waha:arm-2026.10.1`. Features previously offered through Plus have been available in Core since 2026.6.1. WAHA is an unofficial WhatsApp connection and WhatsApp may restrict linked accounts. Only send to authorized destinations. [WAHA GOWS](https://waha.devlike.pro/docs/engines/gows/) · [WAHA Core availability](https://waha.devlike.pro/docs/how-to/waha-plus/) · [Published container tags](https://hub.docker.com/r/devlikeapro/waha/tags)

Open an SSH tunnel from your computer using `ssh -L 3000:127.0.0.1:3000 your-vps`. Open `http://localhost:3000/dashboard`, enter the dashboard credentials and add the API key. Create or start the configured session with GOWS. In WhatsApp on your phone, open Linked devices and scan the session QR. Confirm the session shows `WORKING`. Discover exact recipient IDs through the dashboard or local WAHA API, add them to the client's scope, then verify them with `list_whatsapp_chats`. Use the returned ID, including its suffix. The MCP list filters to your configured allowlist. The operator should reapprove recipient scopes after replacing a linked WhatsApp number. [Dashboard](https://waha.devlike.pro/docs/how-to/dashboard/) · [WAHA Chats API](https://waha.devlike.pro/docs/how-to/chats/)

### Preview verification

Send a test link from an approved HTTPS hostname to a consenting test chat. Choose a page with `og:title`, `og:description` and a publicly accessible `og:image`. Try the same recipient conversation on Android, iOS and WhatsApp Web, and inspect the title, image, description and URL. The sender requests both automatic and high-quality previews. A message ID or `READ` acknowledgement does not establish that a client rendered the card. A slow host or inaccessible metadata may produce a successful plain-text message. [WAHA Send Messages](https://waha.devlike.pro/docs/how-to/send-messages/)

If you already know automatic extraction fails for that page, supply `custom_preview` with a title, description and optionally an uploaded thumbnail. The worker uses the custom endpoint as the one publishing call for that delivery. After a message was accepted, changing its preview would require a separate intentional send. The service does not fetch page metadata itself. Initial preview domains are allowlisted and the WAHA container's bridge rules restrict private-network and host access from GOWS, including redirected connections.

## LinkedIn

For a member, enable Share on LinkedIn and Sign In with LinkedIn using OpenID Connect, and set the author binding to `urn:li:person:<userinfo-sub>`. The login requests `openid profile w_member_social`. For a company page, obtain Community Management API access and grant the connecting member an approved admin or content-admin role. Configure `urn:li:organization:<id>`. The organization flow requests `w_organization_social rw_organization_admin` and verifies the approved role. Use the operator's authenticated browser session and developer tooling to confirm the exact author identifiers. [Posts API](https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/posts-api?view=li-lms-2026-09) · [Organization access](https://learn.microsoft.com/en-us/linkedin/marketing/community-management/organizations/organization-access-control-by-role?view=li-lms-2026-09)

The default `LinkedIn-Version` header is `202609`, with Rest.li protocol 2.0.0. Update the version according to LinkedIn's sunset policy. A URL with no article fields is included in commentary. Add `link_title` and optionally `link_description` to create an article post. JPEG/PNG use Images API. MP4 uses Videos API with multipart upload instructions and processing status. Set `video: true` on the account after confirming app permissions. The service refreshes a token if LinkedIn supplies a refresh token. Otherwise reconnect through the browser flow when needed. [Images API](https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/images-api?view=li-lms-2026-09) · [Videos API](https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/videos-api?view=li-lms-2026-09)

## X

Create a developer app with user-context OAuth 2.0 and write access. Configure the X user's numeric account ID. The authorization flow requests `tweet.read tweet.write users.read media.write offline.access`. Verify API access and sufficient credits in the Developer Console. A missing or expired access grant is surfaced in account status. The worker records a billing rejection separately from a rate limit. Enable `video: true` only after verifying the app can upload video. The backend applies a conservative 280-weight precheck to common text and explicit URLs, with the provider enforcing the exact Unicode, emoji and URL rules. [X pricing](https://docs.x.com/x-api/getting-started/pricing) · [X media](https://docs.x.com/x-api/media/quickstart/media-upload-chunked)

## Instagram

Set up a Meta app with Instagram Login and connect an eligible Business or Creator account. Bind the configured account to the `user_id` returned by the Instagram OAuth identity endpoint. The flow requests `instagram_business_basic,instagram_business_content_publish`. Meta may require advanced access and app review for publishing on accounts outside the app's assigned roles. The configured Graph API default is `v26.0`. JPEG and MP4 Reels are supported. Register the app callback, and make the public Caddy domain reachable so Instagram can fetch the specific media via a signed 30-minute URL. The scheduler creates the media container at publication time and polls before publishing. If it can verify a committed container after an ambiguous response, it records that detail for review. The service keeps approved content at its original resolution and does not transcode. [Meta content publishing](https://developers.facebook.com/documentation/instagram-platform/content-publishing) · [Instagram Login scopes](https://developers.facebook.com/docs/instagram/platform/instagram-api/changelog/)
